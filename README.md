# Tiranga Practice Arcade

A mobile-first, practice-only game landing page inspired by the supplied design reference.

## Run locally

Open `index.html` directly in a browser, or start a local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Files

- `index.html` — page structure
- `styles.css` — responsive visual design
- `script.js` — interactions and animated practice round

> This project contains no real-money betting, payments, wallet, deposits, or cash-out functionality.
